# Muso

Muso is a free, open-source childcare finder for Toronto families, focused on helping Muslim families find centres whose City of Toronto listing includes halal-related information.

## Data source

The directory data is based on the City of Toronto's [A–Z list of licensed child care centres](https://www.toronto.ca/data/children/dmc/a2z/a2za.html) and linked centre listing pages. The app displays the source listing and its recorded update date for each centre.

A City directory tag is not a halal certification. Families should confirm current food sourcing, preparation, and accommodation directly with each centre.

## Run locally

```sh
npm install
npm run dev
```

Muso is intended to remain free and open source for everyone.
